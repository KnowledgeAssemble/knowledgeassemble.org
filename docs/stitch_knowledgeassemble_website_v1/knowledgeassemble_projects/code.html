OpenEdu

An open framework for creating accessible, interactive learning experiences.

Focuses on component-based learning architectures, open curriculum formats, and portable educational tools. OpenEdu enables schools, self-directed learners, and educators to assemble interactive lessons that run anywhere — completely client-side and free from platform vendor lock-in.
